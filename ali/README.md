# Jayden-Inspired Modern Portfolio (React + Tailwind + Bilingual)

بورتفوليو رقمي عصري وتفاعلي مستوحى من قالب **Jayden**، مبني بالكامل بتقنيات الويب الحديثة (React 18، Tailwind CSS، تأثيرات 3D Canvas)، ويدعم اللغتين **العربية (RTL)** و **الإنجليزية (LTR)** مع زر تبديل فوري.

---

## 🚀 كيفية تشغيل المشروع

المشروع مصمم ليعمل مباشرة دون الحاجة لأي تثبيت أو إعدادات معقدة:

### الطريقة 1: التشغيل المباشر
- يمكنك ببساطة فتح ملف `index.html` بالنقر المزدوج عليه في متصفحك المفضل (Chrome, Safari, Edge, Firefox).

### الطريقة 2: تشغيل خادم محلي عبر بايثون
في حال رغبت بتشغيله على خادم محلي (Local Server):
```bash
python3 -m http.server 8000
```
ثم افتح الرابط: `http://localhost:8000` في المتصفح.

## 🎨 التخصيص والتعديل

### 1. تعديل المحتوى والصور والروابط
افتح الملف `src/data.js` وستجد كل قسم مفصولاً بوضوح باللغتين:
- بيانات البروفايل (`profile`): الاسم، المسمى الوظيفي، الصورة، الروابط الاجتماعية.
- قسم البداية (`hero`): النصوص، التخصصات، والإحصائيات الرقمية.
- الأعمال المختارة (`works`): إضافة أو تعديل المشاريع، الصور، التصنيفات، والتفاصيل.
- الخدمات (`services`) ومنهجية العمل (`process`).
- حزمة التقنيات (`tech`) والأسعار (`pricing`) والأسئلة الشائعة (`faq`).

### 2. تغيير اللون الأساسي (Accent Color)
اللون الافتراضي هو البرتقالي النيون الجذاب (`#f3500f`). إذا أردت تغييره لأي لون آخر (مثلاً أزرق `#0066ff` أو بنفسجي `#8b5cf6`):
- عدل المتغير `--primary` في `src/styles.css`.
- عدل كود اللون في `tailwind.config` داخل ملف `index.html`.
